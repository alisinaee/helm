# WP37: release 1.0 prep

## Added

- `tools/install-skills.py`: installs the three skill drafts (`roadmap-dashboard`, `roadmap-update`,
  `roadmap-plan-new`) into `~/.claude/skills` or `--target`. Each draft is checked first (frontmatter name and
  description, and every `roadmap` line in a shell fence parses with `build_parser()`). An existing skill folder
  is refused unless `--yes`, which backs it up as `<name>.bak-<timestamp>`. `--dry-run` changes nothing.
- `make release-check`: lint and unit tests, the UI smoke, the documented commands, and a dry run of the skill install
  into a temporary folder.
- `docs/RELEASE.md`: the release and cutover checklist for split-net, with a rollback for each step, and the list of
  files that refer to `web/legacy.html`.
- `CHANGELOG.md`: the `1.0.0` section; `Unreleased` is empty.
- `README.md`: a new top (what it is, install, first run, the dashboard sections, honest notes); the phone section
  now describes what is built.

## Changed

- `roadmap/__init__.py`: `__version__` is `1.0.0` (the last step of this work package).

## Gaps

- `web/legacy.html` is not deleted here: removing it needs changes to `roadmap/http/static.py` and
  `roadmap/http/security.py`, which this work package does not touch. Steps are in `docs/RELEASE.md` section 6.
- `docs/API.md` still shows `"version": "0.1.0"` in two example replies; that file is outside this work package.
- `docs/GAP-ANALYSIS.md` plans to keep the service on port 8780, while `docs/RELEASE.md` step 3 frees 8765. The
  choice is left to the operator and noted in that step.
