# WP10: projects and hooks installer

- `roadmap/services/projects.py`: project init (template data files only where missing, title taken from the folder), add (folder, data folder and unique id/name/path checked), list, show, remove (files kept), check (each data file parsed with `roadmap.core.parsers`, plus schema version and `roadmap.config.json` settings), migrate (refuses newer files before any write, backs up every data file, then upgrades; restores usage mirroring after the autonomy v2 change), backup (per project, keeps the newest 14).
- `roadmap/services/hooks_install.py`: merges the roadmap hook entries into `<project>/.claude/settings.local.json` (PostToolUse `Agent|Task|Bash`, SubagentStop, Stop; timeout 10; command = absolute `bin/roadmap` path + ` hook`). Recognised by the marker `roadmap hook`, so install is idempotent and writes identical bytes on a re-run. Backs up the old file before changing it. `--replace-legacy` removes only `jobs_auto.py` entries. Uninstall removes only our entries. Status reports installed, stale (another path) or missing per event.
- `roadmap/templates/`: `tasks.json`, `jobs.json`, `autonomy.json` (v2), `roadmap.config.json`, each with `schemaVersion`.
- `roadmap/commands/project.py`, `hooks.py`, `backup.py`: the commands with `--json`. Exit codes: 3 not found, 4 conflict, 5 invalid data file (`check` and `migrate`). `check` in plain mode prints the per-file rows before failing.
- Tests: `tests/unit/test_project_*.py`, `tests/unit/test_hooks_install.py`, `tests/unit/test_backup_cmd.py`.
