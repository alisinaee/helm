## Decisions and gaps
- A Bash command that starts with `roadmap ` but chains another command is denied while blocked (stricter than the spec).
- Queued stop requests for a task stop are not written: queue entries carry no op field. A task stop is enforced
  only through the subagent-to-job mapping (`agent_id` in the hook payload).
- `usage sync` does not call `control.after_write` yet (usage.py is outside this package's file list). The weekly
  limit is read from `usage.json` at each recompute, so it takes effect on the next write or recompute.
- Model caps warn only. Phase caps block every task of that phase.
- The sentinel fast path reads only the default or ROADMAP_HOME state folder, the same rule as paths.state_dir().
- Sonnet check (WP22 requirement): not run in this session.
