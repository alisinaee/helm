# WP53: Planner view (V1)

Adds the Planner view as new files only; the route is not wired yet (WP55 wires it).

- `web/js/views/planner.js`: `plannerHtml(snapshot, state)` (pure markup), `sectionView(vm)`, `bind(el)` (click,
  change and submit delegation, idempotent), `pageAction` not needed. Writes through `cmd.js` `run()`: feature.add,
  feature.set (hold), feature.link, feature.unlink, feature.accept (confirms when not done), feature.rm (only at 0 tasks).
- `web/css/planner.css` (2.5 KB): rows use the shared `.row-grid` tracks with the 13-column template from PLANNER-SPEC
  section 3; numbers right-aligned and tabular; phone (under 640 px) collapses to cards.
- `web/index.html`: one `<link>` line for `planner.css`.
- Tests: `tests/web/render_planner.mjs` (node render, no DOM) and `tests/web/test_planner_view.py` with
  `tests/fixtures/planner_snapshot.json` (7 features, a sub-feature, a shared task, uncovered and orphan callouts,
  a held feature).

Notes for WP55: call `bind(sectionEl)` once when the section first loads. Ops send `unlink` as `{task, feat}`.
