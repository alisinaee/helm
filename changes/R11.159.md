# R11.159: foreground Agent jobs close, quiet agents are swept as stale

- A foreground Agent call (status "completed") or a SubagentStop that came before the job existed now closes the job once, matched by agentId.
- A hook-owned agent job whose transcript is quiet for 15 minutes (or 2 hours with no transcript) is closed as failed with a "stale:" reason; its task is not reset.
- The outputFile key of a background launch is read like output_file.
