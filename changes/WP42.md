# WP42: Haiku-sized skills and skills install

- Two skill templates in `roadmap/templates/skills/`: `roadmap-worker` (2.3 KB) and `roadmap-lead` (2.4 KB), each with a frontmatter trigger, a token budget per workflow, and no commands that do not exist.
- `roadmap skills list [--project ID]` prints the template names, sizes and install state.
- `roadmap skills install [--project ID | --target DIR] [--yes] [--dry-run]` copies the skills into `<project>/.claude/skills/<name>/`. An existing folder is never overwritten silently: without `--yes` it is a conflict (exit 4, nothing written); with `--yes` it is renamed to `<name>.bak-<timestamp>` first. `--dry-run` writes nothing. Missing project or target gives exit 3.
- `skills` is registered in `roadmap/cli.py` COMMAND_MODULES.
- Tests: `tests/unit/test_skills_cmd.py` (install, list, conflict, backup, dry-run, target, project) and `tests/unit/test_skills_cmd_templates.py` (size <= 3200, frontmatter, budget lines, every command in the templates parses with `build_parser()`).
