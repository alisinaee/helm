# WP20: data layer and snapshot

- `roadmap/store/schema.py`: kinds `issues`, `questions`, `comments`, `budget` and `queue`, each at version 1. `tasks`
  stays at 1 (subs, capK and approved are additive keys).
- `roadmap/store/atomic.py`: `write_text(path, payload)` holds the atomic write that `write_json` now uses (same mode and
  symlink rules).
- `roadmap/store/jsonl.py` (new): `append_line`, `raw_lines`, `read_objects` (bad lines counted, not raised) and
  `keep_newest` for activity.jsonl and the `*-archive.jsonl` files.
- `roadmap/core/parsers.py`: `parse_subs` (at most 12, one level, text cut at 80), `capK` on tasks, `approved` on
  phases, `parent` and `role` on jobs (these keys appear only when the file has them), and `parse_issues`,
  `parse_questions`, `parse_comments`, `parse_budget`, `parse_queue`, `parse_activity`. None of them raises.
- `roadmap/services/`: `issues` (200 open, closed beyond 100 archived), `questions` (50 open, answered beyond 50
  archived, `expire` applies the default on timeout), `comments` (20 per target, 150 KB file cap, oldest archived),
  `budget` (limits, `record_job_spend` idempotent per job id, `record_task_tokens` only when the task has no spend),
  `queue` (50 entries), `activity` (`append`, `recent`, newest 500 lines), and `records` (shared load, save and
  validation). Writes take the directory lock and save atomically.
- `roadmap/services/tasks.py`: `add_subtask`, `toggle_subtask` and `undo_subtask`, addressed `P2.4/2` (1-based). Ticking
  the first subtask moves a todo task to partial and never finishes the task.
- `roadmap/core/snapshot.py`: `issues`, `questions`, `comments`, `budget`, `blocked`, `needsYou`, `agents`, `control`,
  `queue` and `activity` (see docs/API.md). `roadmap/services/loader.py` reads the new file names.
- `roadmap/templates/`: `issues.json`, `questions.json`, `comments.json`, `budget.json`, `queue.json`. `project init`
  does NOT write them; the services create each file on its first write.
- `roadmap/services/projects.py`: `migrate` and `backup` cover the five new files and the jsonl files.
- Not done here (WP21): the `S <task> <done|todo> | <title>` plan record was left out, because subs have no id to match
  on upsert. The commands that call these services, and the `job done --tokens` and `task done --tokens` wiring to the
  budget, belong to WP21.
- Tests: `tests/unit/test_wp20_*.py`, and `tests/unit/test_core_golden.py` now strips the WP20 keys and checks they are
  empty for the fixture.
- Docs: data tables in docs/ARCHITECTURE.md and the snapshot section in docs/API.md (additions only).
