# WP43: default port 8780 and doctor port warning

- Default port is 8780 in the global config (roadmap/store/config.py) and in `serve` and `open` (roadmap/commands/serve.py, roadmap/commands/open.py). An existing config keeps its stored port. phonePort stays 8766.
- `roadmap doctor` has a new `port_legacy` row, "Port 8765" (roadmap/services/doctor.py). It warns when something other than the roadmap service listens on 8765, with the cutover fix text. Nothing listening, or the roadmap service itself, is ok.
- `roadmap open --port N` opens that port for one call and does not change the config. Ports outside 1 to 65535 are a usage error (exit 2).
- `roadmap serve` on a busy port exits 4 as before. When the config port is also 8765, the error adds `next: roadmap doctor`.
- Pinned 8765 defaults updated in tests/unit/test_store_config.py and tests/unit/test_phone.py. New tests: tests/unit/test_port_cutover.py (12 tests). They use a temp ROADMAP_HOME, dummy sockets on free ports, and an injected or replaced open runner.
- docs/API.md and docs/ARCHITECTURE.md: port mentions updated. launchd.py does not hardcode the port, so it is unchanged.
