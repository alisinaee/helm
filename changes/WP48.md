# WP48: Workflow view (W2)

- New section Workflow after Agents: `#/p/<id>/workflow[/<timeline|map|table>]`, `#/all/workflow` for every project (8 at most). Range is `f=range:<2h|today|week|all>`, default Today. Table is the default on phones.
- Timeline: swimlanes for Head, haiku, sonnet, agy and other (only the lanes in use), then Queue and Blocked. Bars are coloured by status with tokens only (done, running with a pulsing edge, failed or blocked hatched, queued dashed). Task status times (`at`) show as diamonds on the Head lane. Handoff arrows follow the parent job. Blocker arrows run from the Blocked lane to the task's latest job. The label column and the gutter (job count, tokens K) stay fixed and sticky.
- Map: phases as columns of task cards, in array order. `after` dependencies are dotted arrows. Open blockers show as a badge with the issue id. Stacked on phones.
- Table: one row per job, with the same tracks as the detail strip (`.wf-cols`, rule 0). Stop on running jobs.
- Detail strip under the view. Focus or hover fills it. Start (todo and approved) and Stop go through cmd.js (`task.start`, `task.stop`). Enter or a click opens the task's Details. Arrow keys move between bars and cards.
- The view fetches each project's snapshot itself (5 s cache), since `normalizeSnapshot` does not keep the workflow key.
- Files: `web/js/views/workflow.js`, `web/css/map.css` (4587 bytes, budget 4.5 KB = 4608), one `i-workflow` symbol, one routes entry, one index.html stylesheet line, `tools/ui_smoke.py` section list (required by test_ui_smoke_sections).
- Tests: `tests/web/test_workflow_view.py` with `render_workflow.mjs` and `fixtures/workflow_snapshot.json` (empty, running, blocked, handoff).
- Browser check against a temporary ROADMAP_HOME on 127.0.0.1:8804 with fixtures/demo/alpha: Timeline screenshot at 1440 dark, lanes and gutter aligned. Map (40 cards, 5 phases) and Table (8 rows) checked through the DOM after the pane was hidden, with no console errors. At 375 the document does not overflow and the table scrolls inside its wrapper. Light-mode and 500 px screenshots were not taken.
