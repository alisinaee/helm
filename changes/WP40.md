# WP40: notifications and roadmap watch

## Added

- `roadmap/services/notify.py`: one macOS notification through `osascript -e 'display notification ...'`, sent as an
  argv list (no shell). Text is one line, at most 120 characters, escaped for AppleScript. It is rate limited to one
  per 60 s per (project, kind), kept in `notify.json` in the state directory. The config key `notify` (default true)
  turns it off. Off macOS, without `osascript`, or when it fails, the call returns False and never raises.
- Notifications are sent when a Start is queued (`task.start`), when a blocking question is asked (`ask --block`) and
  the first time a limit blocks a project. A hook recompute (one with a lock timeout) never shows one.
- `roadmap watch [--max 1800] [--project ID]`: blocks until a new queue entry or an answered question appears, then
  prints one line: `start P2.4`, `stop P2.4`, `answer Q3 yes`, or `timeout`. It exits 0. The queue and question files
  are polled by mtime every 2 s. `--json` gives the usual envelope with `event` and `line`.

## Known limits

- `roadmap watch` is not in the stop hook's allowlist while a project is blocked (`ALLOWED_WHILE_BLOCKED` in
  `roadmap/services/hooks.py`). A blocked project denies it. This is left for the hooks owner.
- The global config has no default `notify` key. A missing key means on.
