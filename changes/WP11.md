# WP11: service and doctor

- `roadmap/services/launchd.py`: renders `roadmap/templates/plist.tmpl` (Label `com.roadmap-board.agent`, ProgramArguments `[python, -m, roadmap, serve]`, PYTHONPATH and WorkingDirectory set to the repo, RunAtLoad, KeepAlive, ThrottleInterval 10, Interactive, Aqua, launchd.out and launchd.err in the logs folder). Writes it mode 0644 to `ROADMAP_LAUNCH_AGENTS` or `~/Library/LaunchAgents`. Lifecycle through `launchctl bootstrap|bootout gui/<uid>`, `kickstart [-k]` and `print`, all through an injectable `RUNNER`. Status parses `launchctl print`. Helpers: `prepare_launchd_logs` truncates launchd.out and launchd.err above 5 MB, `follow` and `tail_lines` for `service logs`, `listener_on` (lsof, read-only), `lint_plist` (plutil -lint).
- `roadmap/log.py`: `setup_file_logging` attaches a RotatingFileHandler for server.log (1 MB x 5, mode 0600, also after rollover) with a redaction filter (Bearer, sk-ant-, k=). `access_line` writes method, path without query, status and ms.
- `roadmap/services/doctor.py` and `roadmap/commands/doctor.py`: checks python, repo, shim (executable, on PATH is a warn), config, plist (lint), service loaded, health (127.0.0.1 only, 1 s; a warn when the service is not installed), port (ours or free, else fail with the holder's name), folder and file modes, keychain item (metadata only, no -w), usage (lastError, stale), each project's files and hooks, and log sizes. Exit 0 with no fail, 10 with a fail. `--json` lists every check.
- `roadmap/commands/service.py`: install, uninstall, start, stop, restart, status, logs [-f].
- `roadmap/cli.py` is unchanged. In `tests/unit/test_cli.py`, `doctor` and `service logs` came out of the stub list.
- Pending wiring (not in this package's file list): `commands/serve.py` should call `log.setup_file_logging(paths.logs_dir())` and `launchd.prepare_launchd_logs()` at start.
