# WP23: cmd route, security, task tokens

- `roadmap/services/cmdops.py` (new): registers the control, limit, budget, rules and approval ops into the WP21
  registry (`logs=False`, the services write their own activity line). Source rules: gui skips the agent guard
  (CLAUDECODE is hidden for that call); phone never runs a loosening op. Ops: control.stop/resume/override,
  limit.set, budget.set, task.cap, phase.approve, rules.add/rm/sync.
- `roadmap/services/commands.py`: thread-local `context(source, project)`, `current_source()`, `current_project()`;
  `run()` takes the service's own activity line when it wrote one; `write()` (CLI) recomputes control after the
  write; `task.status` takes optional `note` and whole-number `tokensK` (budget fed once via
  `budget.record_task_tokens`), and its undo restores status and note.
- `roadmap/commands/task.py`: `task done|start|hold` go through the registry op per id, so each change is logged and
  undoable. `--tokens` must be a whole number (exit 5 otherwise, before any write).
- `roadmap/http/routes.py`: `POST /api/v1/cmd` (guard, 4 KB, unknown_op 404, invalid_args 422 with `problems`,
  rate_limited 429, phone allowlist via `app.op_allowed`). `meta` gives the phone its own csrf value only.
- `roadmap/http/security.py`: `RateLimiter` (10 ops per second), `PHONE_OPS`, `phone_csrf`, `CMD_PATH`.
- `roadmap/http/server.py`: App gets `cmd_limiter`, `csrf_token()`, `page_token()`, `op_allowed()`; PhoneApp allows
  POST /cmd only when phoneWrites is true; `phone_writes_enabled()`.
- `roadmap/services/usage.py`: `sync_once` and `push` recompute control for every project afterwards.
- `roadmap/core/snapshot.py` and `roadmap/services/loader.py`: the `control` key (stopped, blocked, reason,
  overrideUntil, warn).
- Tests: `tests/api/test_cmd_route.py`, `tests/api/test_cmd_phone.py`, `tests/unit/test_cmdops.py`. One existing
  assertion in `tests/unit/test_commands_service.py` (the public op list) was updated to the new registry, because
  the spec makes every registered op public.
- Docs: `docs/API.md` (cmd route), `docs/SECURITY.md` (cmd guard, rate limit, phone allowlist).

## Gaps
- Undo of a task's tokens does not reverse the budget spend (the spend is kept once, by design).
- `rules.rm` has an undo (re-add), but the rule gets a new id.
- `422` carries one problem: each op's checks stop at the first failure.
- Phone pages carry no csrf meta; the phone reads its csrf from `/api/v1/meta`.
- A `gui` call briefly clears CLAUDECODE from the process environment under a lock. Other threads in the server
  read it only through the agent guard, so this is safe here, but it is a workaround for `agentguard`, which
  would need a source-aware check to remove it.
