# WP50: planner core

- features: new pure module roadmap/core/features.py. `load(data_dir)` reads features.json through store.schema (missing file = empty, newer or corrupt file = errors entry). `derive(features, tasks, jobs, issues=None)` returns rows, uncovered, orphans, counts, plus two extra keys: `taskTotals` (each task once) and `errors` (strings for skipped features). `validate(features)` returns the error strings. Never raises.
- states (first match): hold, uncovered (0 tasks), done (all tasks done), doing (a done or partial task, or a running job), todo. A parent row unions its own tasks with its children's; children must have no parent (one level). Parent `hold` is the parent's own flag only.
- rules: ids F1..F99, at most 60 features, title <= 80 and acc <= 160 (over the cap = feature left out with an error), prio 1-3 (default 2), parent must be a valid feature, no self-parent, no duplicate id. `accepted` is data only.
- store: schema.py CURRENT gains `"features": 1`.
- parsers: parse_feats() and tasks get an optional `feats` list (at most 3 valid ids, first is primary). Only present when the file has it, so old tasks.json parses as before.
- tests: tests/unit/test_features_core.py (31 tests).
