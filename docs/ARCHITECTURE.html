One write path, files as the database, one snapshot read path, a polling browser app. R7.79.

1. Main flow

2. Two lifecycles

A job

  1. Head launches worker
  2. job start (hook or runner)
  3. task → Doing
  4. commit names task id
  5. job done → done candidate
  6. ask auto-closes
  7. Person reviews

Failures: job fail --reason; out-of-credit engines blocked 6 h (R7.70).

A person's message

  1. Hook logs it as Hn
  2. Head triages + binds to task
  3. Work (jobs above)
  4. Close with ref: commit, job or answer

The Stop hook runs head brief --gate: open Hn items block the session from ending.

3. Known weak spots

  • 1Usage cannot sync from the keychain on this Mac (desktop app login has no token item). roadmap/services/usage.py make usage push the main path; show reading age; refuse launches on a stale reading.
  • 2Task status drift: Doing with no live job. roadmap/services/jobs.py, tasks.py on reap, flag (or revert) Doing tasks with no running job after N minutes.
  • 3Many writers on jobs.json (hooks, CLI, gitops, shell runners, hand edits). roadmap/services/jobs.py, tools/*-job.sh every write through bin/roadmap job; a check that flags edits outside the lock.
  • 4Stop-hook gate loops on the same block. roadmap/commands/head.py (brief --gate) print the next command, not just what is open; same block twice → let the stop through with a note.
  • 5Cursor runs one job at a time; old call form still binds to R7.31. tools/cursor-job.sh a small queue with a lock; require the task id argument.
  • 6agy makes about 1 in 3 wrong claims. docs/reviews/agy-*.md require file:line per claim; the head greps each one before acting; audits only.
  • 7CSS files sit at their size caps. tests/web/test_admin.py (CSS_BUDGET), test_workflow_view.py (MAP_CSS_MAX) move repeated rules into components.css / tokens.css; drop dead selectors.
  • 8Stale browser tabs after a service restart. web/js/api.js (CSRF retry, R7.61) also reload when /api/v1/meta reports a new build or start time.
  • 9Limits written in several places that disagree (CLAUDE.md, skill, runbook, autonomy.json). docs/autonomy.json one source (autonomy.json); docs point to it; launch commands read it.
  • 10Agent jobs are tracked only when the description holds a task id. roadmap/services/hooks.py (DETECTORS) untracked agent → a gate warning, not silence.
  • 11Snapshot poll every 2 s per open tab stats every data file. roadmap/services/loader.py (revision) fine for now; if tabs pile up, cache the revision for ~1 s per project.
