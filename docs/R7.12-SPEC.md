# R7.12 Copy reference (spec)

Goal: every section and row gets a small copy button. It copies a unique reference plus a one-line state, so the person can paste it into an agent chat ("why is this orphan, bind it to the related feature").

## 1. Reference format

`rb:<project>/<kind>/<id>`. The prefix `rb:` marks it as a board ref. `<project>` is the project slug (registry name, never a path).

| kind | id | example |
|---|---|---|
| phase | phase id | `rb:roadmap-board/phase/R3` |
| task | task id | `rb:roadmap-board/task/R3.2` |
| sub | task id + `.s` + index | `rb:roadmap-board/sub/R3.2.s1` |
| feature | F-id | `rb:roadmap-board/feature/F7` |
| issue | I-id | `rb:roadmap-board/issue/I1` |
| question | Q-id | `rb:roadmap-board/question/Q1` |
| job | job id | `rb:roadmap-board/job/j12` |
| research | R-note id | `rb:roadmap-board/research/<id>` |
| section | `<view>.<section>` | `rb:roadmap-board/section/planner.orphans` |
| view | view name | `rb:roadmap-board/view/workflow` |
| project | none | `rb:roadmap-board` |

Rules: ASCII, no spaces, ids are the ids already stored in docs/*.json (stable across reloads). Regex: `^rb:[a-z0-9-]+(/[a-z]+/[A-Za-z0-9._-]+)?$`.

Clipboard text is two lines, max 200 characters total (cut the summary with "..."):

```
rb:roadmap-board/task/R3.2
task "Planner filters" status=doing feature=F7 orphan=no subs=2/5
```

Summary keys by kind: task `status feature orphan subs`; phase `status done/total`; feature `status tasks covered`; issue `status sev`; question `open/answered`; job `state model tokens`; section/view `count`. Values come from the snapshot already in the browser (no new fetch). Titles are quoted and cut to 40 characters.

## 2. `roadmap ref <ref>`

New module `roadmap/commands/ref.py`, added to `COMMAND_MODULES` in roadmap/cli.py. Pure logic in `roadmap/core/refs.py`: `parse(ref)`, `format_ref(project, kind, id)`, `resolve(snapshot, ref) -> lines`. Reuses `core/snapshot.py` and `core/features.py` (orphan flag). Read only.

Output: at most 10 lines, plain `key: value`, no colour. Example:

```
ref: rb:roadmap-board/task/R3.2
title: Planner filters
status: doing  phase: R3  feature: F7  orphan: no
subs: 2/5 done
files: web/js/views/planner.js
next: roadmap task show R3.2
```

`--json` prints the same as one object. Unknown ref: exit EXIT_USAGE with "unknown ref". Unknown project: error that lists `roadmap project list`. Each kind ends with a `next:` line pointing to the existing full command (task/feature/issue/job/ask show).

Skills (roadmap/templates/skills):
- roadmap-worker: "If the person pastes `rb:...`, run `roadmap ref <ref>` before reading files."
- roadmap-lead: "Pasted `rb:` refs: resolve with `roadmap ref`, act with the matching feature/task command (example: orphan task -> `roadmap feature bind`)."

Also one line in docs/AGENT-INTERFACE.md and docs/TOKEN-COST.md (ref lookup is about 60 tokens).

## 3. GUI

- web/js/ref.js (new, about 60 lines): `refOf(project, kind, id)`, `refSummary(kind, item, snap)`, `refButtonHtml(ref, label, summary)`, `copyRef(el)`.
- Button: `<button type="button" class="ref-copy" data-kind="copy-ref" data-ref="..." data-sum="..." aria-label="Copy reference to <label>"><svg><use href="icons.svg#i-copy"/></svg></button>`. Real button, so it is focusable and Enter/Space work. Titles go through `esc()`.
- panel.js onClick: `else if (kind === "copy-ref") copyRef(el);` (one shared delegated handler, no inline handlers, so CSP stays clean).
- copyRef: build text, then `navigator.clipboard.writeText`. Success: `toast("Copied")`. Without clipboard (http on the phone, old browser): fallback in the copyLaunch way, plus a select step: put the text in a readonly input inside the toast, select it, and say "Press and hold to copy". Never `document.execCommand`.
- Icon: one `<symbol id="i-copy">` (two rects) in web/icons.svg.
- Row variant: a fixed last grid column of `1.5rem` on every row grid, present even when empty, so nothing moves (UI rule 0). The button is visible at 0.4 opacity, full on row hover/focus. On touch it is always full.
- Section variant: same button at the right end of the section header, after existing header actions.
- No new max-width, no fixed px widths other than the column token.

| projects | project | projects.list |

Phone listener: refs hold only the project slug and ids. The ref.py output must not print absolute paths either; `files:` uses repo-relative paths. A test checks that no ref or summary has `/Users/` or `~`.

## 5. CSS budget

Total is 64,501 of 65,536 bytes. The new CSS goes in web/css/components.css and must stay under 400 bytes (one `.ref-copy` rule, hover/focus rule, touch rule, one column token). It lands only after the trim worker frees room. `make check-ui` fails if the cap is passed.
